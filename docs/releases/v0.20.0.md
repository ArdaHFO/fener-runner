**Android preview / Android önizleme sürümü**

## English

This preview expands progression, collectibles and social play while improving the run-to-menu flow.

### Highlights

- Return to the main menu directly from pause, with the current run's earnings settled once.
- Explore the workshop's **Powers**, **Abilities** and **Garage** tabs.
- Upgrade all 15 powers through three levels and invest in five permanent abilities.
- Choose among three animated chase vehicles. Additional vehicles are purchased with earned chicks and are cosmetic.
- Collect the rare hen to scatter 12 chicks, increasing to 18 with the corresponding upgrade.
- Combine Magnet and Double Chicks for bonus collectible rewards after clean obstacle passages.
- Benefit from improved lateral chick collection during lane changes.
- Add friends by full player name, accept requests and send in-game invitations to Relay rooms.

### Installation and compatibility

The download targets **Android 8.0+ on ARM64 devices**. It is a **34.8 MiB** APK with package ID `com.fenerrunner.prototype`, version `0.20.0` and version code `20`. No extra OBB file is needed.

The recorded v0.19 and v0.12 APKs share its signing certificate. Install as an update to keep compatible local data. The preview uses local debug-key signing with Development Build disabled. It is not a store release.

The game UI is Turkish. English and Turkish installation, development and multiplayer guides are included in the repository. Both players need the same version and an internet connection for multiplayer. Invitations require both apps to be open.

### Verification

The release baseline passed 2,993 conditions across 27 native Unity Play Mode stages, 41 APK checks and 21 packaged-service checks. These are project-specific conditions rather than Unity Test Framework case counts. The APK has not been validated on physical phones in the recorded run. Device performance, Android keyboard interaction and two-phone play remain testing priorities.
