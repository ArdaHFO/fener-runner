# Changelog / Sürüm notları

## 0.20.0 — Android preview

- Return from the pause screen to the main menu with run settlement handled once.
- Three workshop tabs, 15 upgradeable powers and five permanent abilities.
- Three selectable chase vehicles with persistent ownership and selection.
- More forgiving chick collection during lane changes and a hen bonus that scatters collectible chicks.
- Friends, requests, presence and explicit in-game invitations for two-player ghost races.
- Continued regression coverage across controls, collisions, audio and lifecycle behavior.

The first public repository publication adds English/Turkish guides, real Editor screenshots, portable developer launch scripts, repository checks and a downloadable copy of the existing APK. Four Editor capture destinations were made portable. Gameplay and APK were not changed by publication.
